# PetrolBot

Telegram-бот для отслеживания средней цены бензина АИ-95 в Санкт-Петербурге.
Получает среднюю цену из [таблицы Бензинстатуса](https://benzinstatus.ru/sankt-peterburg/ceny/)
и уведомляет подписчиков об изменениях.

## Возможности

- Показывает среднюю цену АИ-95 по кнопке «Узнать актуальную цену».
- Автоматически проверяет цену раз в час.
- Отправляет подписчикам уведомления при изменении цены на 1 копейку и более.
- Сообщает, если получить цену с сайта не удалось.

## Как пользоваться

1. Отправьте боту команду `/start`, чтобы подписаться на уведомления.
2. Нажмите «Узнать актуальную цену», чтобы получить цену из источника.
3. Получайте уведомления об изменениях автоматически.

Бот показывает среднюю цену по городу: стоимость на конкретной АЗС может отличаться.
Свежесть данных зависит от обновления источника.
Для АИ-95 используется колонка «Средняя», а не медиана или цена отдельной АЗС.

После перезапуска первая успешная автоматическая проверка запоминает исходную цену.
Последующие проверки сравнивают её с новой и при изменении отправляют уведомления.

## Тестовый бот

Для локальной проверки изменений предусмотрен отдельный тестовый запуск.
Создайте тестового бота через [@BotFather](https://t.me/BotFather) и сохраните
его токен в файле `.env.test` в папке проекта:

```dotenv
TOKEN=токен_тестового_бота
```

После установки зависимостей в окружение `venv` запустите:

```sh
venv/bin/python run_test_bot.py
```

Программа выведет ссылку на тестового бота. Откройте её в Telegram,
отправьте `/start` и нажмите «Узнать актуальную цену». Для остановки нажмите Ctrl+C.

Тестовый запуск использует отдельный токен и базу `subscribers.test.db`,
поэтому его можно запускать одновременно с рабочим ботом.
Файл `.env.test` и тестовая база исключены из Git.

## Технологии

Python, python-telegram-bot, Requests, Beautiful Soup и SQLite.
